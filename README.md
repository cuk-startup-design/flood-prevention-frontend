# 서울시 침수 예방 시스템

> 실시간 공공데이터로 서울 25개 구의 침수 위험도를 분석하고,
> 시민이 직접 빗물받이·하수구 문제를 신고하면 행정이 처리하는 통합 플랫폼입니다.

---

## 서비스 한눈에 보기

```
시민                              관리자(행정)
 │                                    │
 ├─ 지도에서 우리 동네 위험도 확인       │
 │                                    │
 ├─ 하수구 막힘 발견 → 사진 촬영        │
 │   → 체크리스트 선택 → 신고 접수      │
 │                                    ├─ 신고 목록 확인
 │                                    ├─ 사진·위치 검토
 │◄── 알림: "신고가 접수되었습니다" ────┤
 │                                    ├─ 승인 / 반려 처리
 │◄── 알림: "신고가 처리 완료되었습니다" ┘
 │
 └─ 마이페이지에서 처리 내역 + 서울페이 포인트 확인
```

---

## 주요 기능

### 1. 실시간 침수 위험도 지도

서울 25개 구의 현재 침수 위험 수준을 지도 위에 색상으로 표시합니다.

**어떻게 보이나요?**
- 🔴 빨간색 — 위험 (즉시 주의 필요)
- 🟠 주황색 — 보통 (경계 필요)
- 🟢 초록색 — 낮음 (안전)

**사용 흐름**

```
앱 실행
  └─► 지도 화면 진입
        ├─ [위치 권한 허용] → 내 위치 중심으로 지도 표시
        │                     각 구별 위험 색상 히트맵 표시
        │                     우하단 버튼으로 언제든 내 위치로 재이동
        │
        └─ [위치 권한 거부] → 안내 모달 계속 표시
                              브라우저 설정에서 허용 후 새로고침
```

---

### 2. 빗물받이·하수구 신고

길을 걷다 막힌 빗물받이나 문제 있는 하수구를 발견하면 바로 신고할 수 있습니다.

**사용 흐름**

```
신고하기 버튼 탭
  └─► 카메라 실행 → 현장 사진 촬영
        └─► 체크리스트 화면
              ├─ 위험 징후: 악취 심함 / 물이 안 빠짐 / 오물·쓰레기 쌓임
              ├─ 주의 징후: 낙엽·흙으로 덮임 / 덮개 파손 / 배수 속도 느림
              └─ 기타:     주변 지반 침하 / 위치 식별 어려움
                    │
                    └─► 해당 항목 선택 후 [신고 완료] 탭
                          ├─ 사진 자동 업로드
                          ├─ GPS로 현재 위치(구) 자동 인식
                          └─► 신고 접수 완료 → 알림 수신
```

**신고 항목 분류**

| 카테고리 | 항목 |
|---------|------|
| 위험 징후 | 악취가 심하게 난다 / 물이 고여 빠지지 않는다 / 오물·쓰레기가 쌓여있다 |
| 주의 징후 | 낙엽·흙으로 덮여있다 / 격자 덮개가 파손·변형됐다 / 배수 속도가 느리다 |
| 기타 | 하수구 주변이 침하됐다 / 위치 식별이 어렵다 |

---

### 3. 관리자 대시보드

행정 담당자가 접수된 신고를 검토하고 처리하는 전용 화면입니다.

**사용 흐름**

```
관리자 로그인
  └─► 대시보드 메인
        ├─ 총 신고 수 / 처리율 / 최근 7일 추이 그래프
        └─ 증상 분포 도넛 차트 (가장 많이 신고된 증상 TOP 6)

  └─► 신고 관리 탭
        ├─ [대기] 탭 → 처리 전 신고 목록
        ├─ [완료] 탭 → 승인 완료된 신고
        └─ [반려] 탭 → 반려된 신고
              │
              └─► 신고 클릭 → 상세 모달
                    ├─ 신고 사진 (클릭 시 원본 보기)
                    ├─ 정확한 위치: "강동구 천호동" 수준으로 표시
                    ├─ 신고 항목 목록
                    ├─ 신고 일시 및 신고자 이름
                    │
                    ├─ [승인] → 시민에게 "처리 완료" 알림 자동 발송
                    └─ [반려] → 시민에게 "반려" 알림 자동 발송
```

---

### 4. 실시간 알림

신고 상태가 바뀔 때마다 앱 안에서 즉시 알림을 받습니다. 앱을 켜두지 않아도, 다음에 접속하면 놓친 알림을 모두 확인할 수 있습니다.

**알림이 오는 시점**

| 시점 | 알림 내용 |
|------|---------|
| 신고 접수 직후 | 📋 "신고가 접수되었습니다" |
| 관리자가 승인 시 | ✅ "신고가 처리 완료되었습니다" |
| 관리자가 반려 시 | ❌ "신고가 반려되었습니다" |

**사용 흐름**

```
앱 상단 알림 아이콘 (🔔) → 읽지 않은 알림 수 배지 표시
  └─► 알림 탭 진입
        ├─ 최신순으로 알림 목록 표시
        ├─ 읽지 않은 알림은 색상 강조
        └─ 탭 진입 시 모두 읽음 처리
```

---

### 5. 마이페이지 & 서울페이

신고 활동에 따라 서울페이 포인트가 쌓이고, 내 신고 이력을 확인할 수 있습니다.

**서울페이 적립 기준**

> 관리자가 신고를 **승인(처리 완료)** 할 때마다 **500P** 적립

**사용 흐름**

```
마이페이지 진입
  ├─ 총 신고 수 / 처리 완료 건수 / 누적 서울페이 포인트 표시
  ├─ 최근 적립 내역 (처리 완료된 신고 기준)
  └─ 프로필 편집: 이름, 전화번호, 알림 설정
```

## 공공 API 활용

이 서비스는 서울시가 공개한 실시간 데이터를 직접 가져와 위험도 판단에 활용합니다.

### 사용 중인 공공 API

| API 이름 | 제공처 | 가져오는 정보 |
|---------|--------|-------------|
| 서울시 강수량 정보 (OA-1168) | 서울 열린데이터광장 | 서울 25개 구별 현재 강수량 (mm) |
| 하수관로 수위 모니터링 (OA-2527) | 서울 열린데이터광장 | 서울 25개 구 하수관 내부 수위 (m) |
| 카카오맵 SDK | 카카오 | 지도 표시, 위험도 색상 시각화, 위치 → 주소 변환 |

### 각 API가 어떻게 쓰이나요?

**강수량 API (OA-1168)**
서울 전역 측정소의 강수량 데이터를 실시간으로 받아옵니다.
현재 얼마나 비가 오는지를 수치로 환산해 위험도 계산에 반영합니다.

**하수관로 수위 API (OA-2527)**
서울 25개 구 각각의 하수관 내 수위를 실시간으로 받아옵니다.
하수관이 차오를수록 빗물이 역류·범람할 위험이 커지므로, 이 수치를 위험도 계산에 반영합니다.

**카카오맵 SDK**
- 지도 위에 구별 위험도를 색상으로 시각화
- 관리자 대시보드에서 신고 GPS 좌표를 "강동구 천호동"처럼 사람이 읽기 쉬운 주소로 변환

## 침수 위험도 판단 방법

단순히 "비가 많이 온다" 하나만 보지 않고, **3가지 요소를 종합**해 각 구의 위험 수준을 결정합니다.

### 3가지 판단 요소

```
침수 위험도 = 강수량(50%) + 하수관로 수위(30%) + 지역 취약성(20%)
```

| 요소 | 비중 | 의미 |
|------|------|------|
| 현재 강수량 | 50% | 지금 얼마나 비가 오고 있는가 |
| 하수관로 수위 | 30% | 하수관이 얼마나 차 있는가 |
| 지역 취약성 | 20% | 이 구는 원래 침수에 얼마나 취약한가 |

### 왜 3가지를 합치나요?

- **강수량만으로는 부족합니다.** 같은 양의 비라도 하수관이 이미 꽉 차있으면 훨씬 위험합니다.
- **하수 수위만으로도 부족합니다.** 지역마다 지형·하수 용량이 달라 같은 수위여도 위험도가 다릅니다.
- **지역 취약성**은 과거 침수 피해 이력, 불투수 면적(아스팔트 비율), 하천 유역 특성을 반영한 값으로, 학술 논문(2018, 한국수자원학회) 기반의 AHP 분석 결과를 적용했습니다.

### 위험 등급 판정 기준

```
계산된 점수가...

  0.55 이상  →  🔴 위험   (지도에 빨간색)
  0.28 이상  →  🟠 보통   (지도에 주황색)
  0.28 미만  →  🟢 낮음   (지도에 초록색)
```

### 지역 취약성 점수 (일부)

과거 침수 피해가 잦거나 배수 인프라가 취약한 지역일수록 높은 점수가 부여됩니다.

| 구 | 취약성 | 주요 사유 |
|----|-------|---------|
| 영등포구 | 매우 높음 | 도림천 유역, 반복적 침수 피해 |
| 구로구 | 매우 높음 | 도림천 유역, 저지대 밀집 |
| 금천구 | 매우 높음 | 안양천 합류부, 낮은 지대 |
| 강남구 | 높음 | 2010·2011년 대규모 침수 이력 |
| 강서구 | 높음 | 한강변 저지대, 불투수면 높음 |
| 기타 구 | 보통~낮음 | 지형·피해이력 종합 평가 |

## 향후 추가 가능 기능

- **기상청 단기예보 연동** — 앞으로 비가 얼마나 올지 예측해 사전 경보 발송
- **침수 대피소 안내** — 위험 지역 인근 학교·복지관 등 대피 가능 시설 지도 표시
- **신고 밀집 지역 시각화** — 같은 구역에 신고가 몰리면 지도에서 바로 확인 가능
- **배수관 현황 통합** — 빗물받이 신고와 하수관로 수위를 연계한 정밀 위험 예측
